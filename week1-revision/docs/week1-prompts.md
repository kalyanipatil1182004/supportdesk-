
# Week 1 Revision – Effective AI Prompts

## 1. Debugging Prompt

Act as an experienced TypeScript developer.
Analyze the following code and identify the error.
Explain the root cause in simple language and provide
a corrected solution without changing unrelated code.

## 2. Code Generation Prompt

Act as a senior TypeScript developer.
Create a Ticket Manager class with methods to create,
view, update and close tickets.
Use interfaces, proper types and input validation.
Explain the implementation step by step.

## 3. Jest Testing Prompt

Act as a Jest testing expert.
Write at least 8 unit test cases for the TicketManager class.
Cover successful operations, invalid inputs, error handling
and unique ticket IDs. Use clear test descriptions.

## 4. Code Review Prompt

Review the following TypeScript code.
Check code quality, naming conventions, error handling,
type safety and possible bugs.
Suggest improvements without unnecessarily changing
the existing functionality.

## 5. Error Explanation Prompt

Explain the following TypeScript or npm error
in beginner-friendly language.
Identify why it happened and provide the minimum
PowerShell commands required to fix it.
Explain what each command does.
